# Custom-Recreator-3D-

Dépôt de données pour le projet Custom Recreator 3D.
Ce dépôt Git contient toute la documentation nécessaire pour utiliser la machine Recreator 3D.

IMPORTANT : il faudra racheter un écran pour utiliser la machine : https://www.amazon.fr/%C3%89cran-imprimante-12864-plaque-support/dp/B09VSXB6WN

Contenu du dépôt
1. Firmware
Dans le sous-dossier dédié, vous trouverez le firmware à installer sur la machine.
Procédure d'installation :

Copiez les fichiers du firmware sur une carte SD vierge.
Insérez la carte SD dans la machine éteinte.
Allumez la machine pour finaliser l'installation.
2. Fichiers d'impression
Dans le sous-dossier code_4_print, vous trouverez les fichiers nécessaires pour imprimer avec la machine.
